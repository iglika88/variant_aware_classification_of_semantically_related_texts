# Variant-Aware Classification of Semantically Related Texts

This repository contains artefacts and code associated with the article bearing the same name. 

In the framework of the project, three experiments are carried out. Each experiment is associated with one or more datasets that contain semantically comparable texts with distinct associated structural and linguistic differences: 

(1) Financial News Reports (differences in journalistic style),  
(2) Fairy Tales (differences in authorial style and time period), and  
(3) Simplification (differences in complexity)
