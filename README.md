# Variant-Aware Classification of Semantically Related Texts

This repository contains the artefacts and code associated with the following article:

> Soha Delbani, Amjad Ghemrawi, Oussama Masri, Rami Radwan, and Iglika Nikolova-Stoupak. 2026. *From Stemmatology to NLP: Variant-Aware Classification of Semantically Related Texts*. CLEAR-TEXT Workshop at CLIB 2026 (Computational Linguistics in Bulgaria), Sofia, Bulgaria.

The project comprises three experiments. Each experiment is associated with one or more datasets containing semantically comparable texts with distinct structural and linguistic characteristics:

(1) Financial News Reports (differences in journalistic style),  
(2) Fairy Tales (differences in authorial style and time period; differences in complexity in the case of adaptation for children), and  
(3) Simplification (differences in complexity)
